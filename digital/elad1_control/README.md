# ELAD1_CONTROL hardening (LibreLane)

Turns `src/elad1_control.v` into a placed-and-routed sky130_fd_sc_hd macro.

    bash flow/digital.sh smoke     # once: LibreLane's own smoke test (checks the toolchain)
    bash flow/digital.sh harden    # synthesis -> floorplan -> placement -> CTS -> routing -> signoff
    bash flow/digital.sh gl        # the RTL testbench (284 checks) on the hardened gate netlist

Signed off 2026-10-22 (LibreLane v3.1.0.dev3, sky130A): DRC 0 (router, Magic, KLayout), LVS 0,
antenna 0, max slew/cap 0 in all 9 corners, setup slack +10.6 ns and hold slack +0.12 ns at
50 MHz, gate-level 284/284.

| Setting | Value | Why |
| --- | --- | --- |
| Die | 140 x 46 um | package plan was 126 x 40; at 81 % fill 6 nets had slew violations in the slow corner, 140 x 46 gives 62 % and none |
| Clock | `clk`, 20 ns | 50 MHz = the controller's maximum (TT clock 10 MHz nominal) |
| Margins | 2 rows top/bottom, 6 sites left/right | defaults (4 rows, 12 sites) leave too little core in a small die |
| Slew repair | 30 % before routing, 20 % after | stricter than the defaults (20 / 10 %) |
| Routing | up to met4, PDN on met4 only (`PDN_MULTILAYER` false) | Tiny Tapeout analog: met5 is not available to the design |
| Power | `VPWR` / `VGND` met4 stripes every 50 um | stripes are where the analog top connects the macro |
| Pins (`pin_order.cfg`) | West: clk, rst_n, ena, ui_in; East: en_*, clr_*, hen, agg_clk; North: status | inputs face the TT pins, outputs face ELAD1_ANALOG_CORE |

In git: `final/gds`, `lef`, `lib`, `nl`, `pnl`, `spice` and `metrics.*` (what integration needs).
Not in git: `runs/` and the intermediate views in `final/` (regenerated by `harden`).
